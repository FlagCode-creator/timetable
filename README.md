# โปรแกรมจัดตารางสอน

โปรแกรมจัดตารางสอนสำหรับสถานศึกษาอาชีวศึกษา ใช้จัดตารางของครูทุกคนและกลุ่มเรียนทุกกลุ่มพร้อมกัน
มีระบบตรวจคาบชน จัดอัตโนมัติ และพิมพ์ตารางสอนรายครูตามแบบฟอร์มของวิทยาลัยได้ (A4 แนวนอน)

## วิธีเปิดใช้งาน

- **เปิดผ่านเว็บ (GitHub Pages):** https://flagcode-creator.github.io/timetable/
- **หรือเปิดจากเครื่อง:** ดาวน์โหลด repo แล้วดับเบิลคลิกไฟล์ `index.html` (Chrome/Edge) ไม่ต้องติดตั้งอะไร

### ตั้งค่า GitHub Pages (ทำครั้งเดียว)

1. ไปที่ repo บน GitHub → **Settings** → **Pages**
2. หัวข้อ **Build and deployment** → Source เลือก **Deploy from a branch**
3. Branch เลือก branch หลักของ repo และโฟลเดอร์ **/ (root)** → กด **Save**
4. รอประมาณ 1–2 นาที แล้วเปิดลิงก์ด้านบน ทุกครั้งที่ push ขึ้น branch นั้น หน้าเว็บจะอัปเดตเอง

> ข้อมูลเก็บไว้ในเบราว์เซอร์ของเครื่องที่ใช้งานเท่านั้น ควรกด **บันทึกไฟล์สำรอง** เป็นระยะ
> ถ้าต้องการย้ายงานไปทำต่อที่เครื่องอื่น ให้ใช้ไฟล์สำรองนี้ (ตั้งค่า → เปิดไฟล์สำรอง)

### ตรวจสอบข้อมูล (กลุ่มเรียนซ้ำ ฯลฯ)

ปุ่ม **ตรวจสอบ** มุมขวาบนตรวจให้ตลอดเวลา (สีแดง = ต้องแก้, สีส้ม = ควรตรวจ)
- **กลุ่มเรียนรหัสซ้ำ** หรือ **ชื่อซ้ำ** (เทียบโดยไม่สนช่องว่าง/จุด เช่น "ปวช.2 สารสนเทศ 67" กับ "ปวช.2สารสนเทศ67") → กด "เก็บอันนี้ รวมที่เหลือเข้ามา" ระบบย้ายรายวิชาและตารางมารวมให้
- **กลุ่มเรียนลงวิชาเดียวกันซ้ำ** (เช่น ครู 2 คนสอนวิชาเดียวกันให้กลุ่มเดียวกัน)
- **กลุ่มเรียนเรียนซ้อนเวลา** ทั้งตารางรายสัปดาห์และทั้งเทอม
- **ชั่วโมงเกินเวลาที่มี** (ชม./สัปดาห์ของกลุ่มมากกว่าช่องที่จัดได้)
- รายการที่ยังไม่เลือกกลุ่มเรียน, ชื่อครูซ้ำ, รหัสวิชาซ้ำ

ตอนวางรายชื่อกลุ่มเรียนจาก Excel ถ้าพบกลุ่มซ้ำจะแจ้งเตือนทันที และในตารางกลุ่มเรียนจะมีป้าย "ซ้ำ" ที่แถวนั้น

### เงื่อนไขการจัดตาราง

- **วันเรียน**: แต่ละวันเลือกได้ `เปิดสอน` / `ห้ามจัด` / `ไม่แสดง`
  - *ห้ามจัด* (เช่น วันศุกร์) ยังแสดงแถววันนั้นในใบตารางเป็นช่องว่าง แต่วางคาบไม่ได้
  - *ไม่แสดง* เอาแถววันนั้นออกจากใบตาราง
- **กิจกรรมประจำ** เช่น Home Room ทุกวันพุธ คาบ 1 (08:00–09:00): กดปุ่มเดียวสร้างให้ทุกกลุ่มเรียน และล็อกไว้
  - ผู้สอน = ครูที่ปรึกษาของกลุ่ม โดย **ครู 1 คนได้ 1 กลุ่มก่อน**
  - กลุ่มที่ไม่มีชื่อครูที่ปรึกษา / ชื่อไม่ตรงกับรายชื่อครู / ครูได้กลุ่มอื่นไปแล้ว จะ**เว้นว่าง**ไว้ เลือกครูเองได้ที่หน้าภาระงานสอน (ตัวกรอง "ยังไม่มีครู")
  - กดอัปเดตซ้ำได้ ระบบจะไม่ทับครูที่เลือกไว้แล้ว
- **ช่วงเวลาห้ามจัด**: ใช้กับทุกคน เช่น ประชุมครูวันจันทร์คาบ 8–9

### 2 โหมดตาราง

- **ตารางรายสัปดาห์**: เรียนวัน/เวลาเดิมทุกสัปดาห์ (ค่าเริ่มต้นของทุกวิชา)
- **ตารางทั้งเทอม**: สำหรับวิชาที่ต้องการวางเป็นรายวันจนครบชั่วโมงทั้งเทอม
  - ตั้งที่หน้าภาระงานสอน ช่อง "การจัด" → "ทั้งเทอม" และกำหนด "วันละ … ชม."
  - ชั่วโมงทั้งเทอม = ชม./สัปดาห์ × 18 สัปดาห์ เช่น 3 × 18 = 54 ชม. วันละ 4 ชม. = **13 วัน + 2 ชม.**
  - หน้าจัดตาราง → ตารางทั้งเทอม: แสดง **18 ตาราง (สัปดาห์ละ 1 ตาราง)** แบบเดียวกับตารางรายสัปดาห์ แถบเลขสัปดาห์ด้านบนกดเพื่อเลื่อนไปสัปดาห์นั้น
  - คลิกวิชาทางขวา แล้วคลิกคาบในตารางของสัปดาห์ที่ต้องการ (หรือลากวาง) ไปเรื่อย ๆ จนครบ หรือกด **เติม** ให้วางต่อเนื่องอัตโนมัติ
  - สีเทา = ตารางรายสัปดาห์ (มีทุกสัปดาห์) · สีตามวิชา = วิชาทั้งเทอม · ช่องเขียว = วางได้ · ช่องแดง = ชน
  - คลิกช่องที่วางแล้ว → คลิกช่องเขียวในสัปดาห์ไหนก็ได้ (หรือลาก) เพื่อย้าย และใช้เครื่องมือเหมือนรายสัปดาห์: **แบ่งเวลา (หัว+ท้าย), หัว +1/−1, ท้าย +1/−1, เอาออก** (เพิ่มได้ไม่เกินชั่วโมงทั้งเทอม)
  - แถบเครื่องมือและแถบเลขสัปดาห์ค้างอยู่ด้านบนเสมอ ใช้ได้ทันทีไม่ว่าจะเลื่อนไปสัปดาห์ไหน
  - พิมพ์ "ทั้งเทอม" ได้ตารางจริงของทุกสัปดาห์ หน้าละ 2 สัปดาห์
  - ตรวจชนกับตารางรายสัปดาห์และวิชาทั้งเทอมอื่นในสัปดาห์เดียวกัน

### เครื่องมือ (แถบเหนือตาราง)

เลือกคาบในตาราง (หรือการ์ดที่ยังไม่ได้จัด) แล้วใช้เครื่องมือบนแถบ:
- **แบ่งเวลา (หัว + ท้าย)**: หั่นก้อน เช่น 4 คาบ เป็น 1+3, 2+2, 3+1 แล้วลากส่วนท้ายไปวางที่อื่นได้
- **หัว / ท้าย +1 −1**: เพิ่ม/ลดคาบที่หัวหรือท้ายของก้อน ใช้เพิ่มเวลาให้ Block Course (ก้อนปกติคร่อมพักกลางวันไม่ได้)
- **รวมก้อนถัดไป**: รวมก้อนที่แบ่งไว้กลับเป็นก้อนเดียว
- **ล็อก / เอาออก**: ล็อกไม่ให้จัดอัตโนมัติย้าย หรือเอาคาบออกจากตาราง

แต่ละวิชามีสีประจำ (โทนอ่อน) และช่องตารางทุกช่องขนาดเท่ากัน ข้อความยาวจะตัดเป็น "…" (ชี้ค้างเพื่อดูเต็ม)

### หลักการสำคัญ

- **ภาระงาน 1 แถว** = ครู 1 คน + วิชา 1 วิชา + กลุ่มเรียน 1 กลุ่ม (หรือหลายกลุ่มที่**เรียนรวม**ในเวลาเดียวกัน ซึ่งชั่วโมงสอนของครูนับครั้งเดียว)
  ถ้าสอนวิชาเดียวกันให้หลายกลุ่มแต่แยกเวลากัน ให้เพิ่มเป็นคนละแถว (ปุ่ม ⧉ ช่วยทำสำเนา)
- **รูปแบบคาบ** เช่น `3` = เรียนติดกัน 3 คาบ, `2+2` = แบ่ง 2 ครั้ง ครั้งละ 2 คาบ ถ้าเว้นว่างไว้ ระบบคิดจาก ท.+ป. ของรายวิชาให้เอง
- **Block Course** = เรียนติดกันเป็นก้อนใหญ่ทุกสัปดาห์ ก้อนคาบข้ามพักกลางวันได้ เช่น `7` = คาบ 1–7
- **ตรวจชน**: ครูสอนซ้อน, กลุ่มเรียนเรียนซ้อน, คาบที่ตั้งไว้ว่าไม่ว่าง และช่วงเวลาห้ามจัด
  - ห้องเรียนชนกัน **ไม่ตรวจ** เป็นค่าเริ่มต้น เปิดได้ที่ เงื่อนไข → ห้องเรียน → "ตรวจห้องเรียนชนกัน"
- **เวลาไม่ว่าง**: ในหน้าจัดตาราง เลือกครูหรือกลุ่มเรียน → โหมด "เวลาไม่ว่าง" → คลิกช่องที่ไม่ว่าง
- **ล็อกคาบ**: คลิกคาบในตาราง → ล็อก คาบที่ล็อกไว้จะไม่ถูกย้ายหรือล้างเวลากดจัดอัตโนมัติ/ล้างตาราง

### รูปแบบข้อมูลสำหรับ "วางจาก Excel"

| ข้อมูล | คอลัมน์ |
|---|---|
| กลุ่มเรียน | วางรายชื่อที่คัดลอกจากระบบของวิทยาลัยได้ตรง ๆ (ระดับชั้น, (หลักสูตร) สาขาวิชา, รหัสกลุ่ม, ชื่อกลุ่ม, ประเภทวิชา, จำนวนผู้เรียน, ครูที่ปรึกษา) หรือแบบง่าย `รหัสกลุ่ม, ชื่อกลุ่ม` |
| ครู | ชื่อ-สกุล, วุฒิการศึกษา, แผนกวิชา, สาขาวิชา, หน้าที่พิเศษ |
| รายวิชา | รหัสวิชา, ชื่อรายวิชา, ท., ป., น. (หรือ `รหัสวิชา, ชื่อรายวิชา, 1-2-2`) |
| ห้อง | ชื่อห้อง, ใช้พร้อมกันได้ (ใส่ "ใช่") |
| ภาระงานสอน | ชื่อครู, รหัสวิชา (หรือชื่อกิจกรรม เช่น Home Room), รหัสกลุ่ม (หลายกลุ่มคั่นด้วย `,`), ห้อง, รูปแบบคาบ, Block Course (ใส่ "ใช่"), ทั้งเทอม (ใส่ "ใช่") |

ถ้ารหัสหรือชื่อซ้ำกับข้อมูลที่มีอยู่ ระบบจะปรับปรุงข้อมูลเดิมแทนการเพิ่มใหม่
