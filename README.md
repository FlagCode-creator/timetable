# โปรแกรมจัดตารางสอน

โปรแกรมจัดตารางสอนสำหรับสถานศึกษาอาชีวศึกษา ใช้จัดตารางของครูทุกคนและกลุ่มเรียนทุกกลุ่มพร้อมกัน
มีระบบตรวจคาบชน จัดอัตโนมัติ และพิมพ์ตารางสอนรายครูตามแบบฟอร์มของวิทยาลัยได้ (A4 แนวนอน)

## วิธีเปิดใช้งาน

## ขั้นตอนการใช้งาน

เปิดโปรแกรมแล้วเริ่มที่ **หน้าแรก** — มีการ์ดบอกทีละขั้น ทำขั้นไหนเสร็จจะมีเครื่องหมายถูก

| ขั้น | แท็บ | ทำอะไร |
|---|---|---|
| 1 | ข้อมูล | ใส่รายวิชาและกลุ่มเรียน — ที่หน้าแรกกดปุ่ม **ใช้แผนกคอมพิวเตอร์ ภาคเรียนที่ 2/2569** ได้ในคลิกเดียว หรือ **นำเข้าแผนการเรียน** (วางจาก Excel) |
| 2 | ข้อมูล → ครู | ใส่รายชื่อครู (พิมพ์หรือวางจาก Excel) |
| 3 | มอบวิชาให้ครู | ซ้าย = วิชาที่ยังไม่มีครู, ขวา = การ์ดครู · **คลิกการ์ดครู แล้วคลิกวิชาทางซ้าย** (หรือลากวิชาไปวางบนการ์ดครู) · คลิกชิปวิชาบนการ์ดเพื่อแก้ (ชั่วโมง, ห้อง, Block Course ฯลฯ) |
| 4 | จัดตาราง | กด **จัดอัตโนมัติ** แล้วปรับเองได้ (คลิกคาบ → เครื่องมือแบ่ง/หัว ±1/ท้าย ±1 จะขึ้นด้านบน) · ถ้ามีวิชาจัดทั้งเทอมจะมีปุ่มสลับ **รายสัปดาห์ / ทั้งเทอม** |
| 5 | พิมพ์ | ตารางสอนรายครู, ตารางเรียนรายกลุ่ม, ตารางการใช้ห้อง, ตารางทั้งเทอม — พิมพ์หรือบันทึกเป็น PDF |

ปุ่ม **ตั้งค่า** มุมขวาบนรวมเรื่องที่ไม่ได้ใช้บ่อย: เงื่อนไขการจัดตาราง, ตรวจสอบข้อมูล, ข้อมูลสถานศึกษา, บันทึกไฟล์สำรอง
ปุ่มสีแดง **ต้องแก้ n เรื่อง** จะขึ้นเฉพาะเมื่อพบปัญหา (กดเพื่อดูรายละเอียด)

ในหน้าข้อมูล คอลัมน์ **วิชาที่สอน / วิชาที่เรียน** เป็นตัวนับอัตโนมัติ (แก้ตรงนั้นไม่ได้) กดที่ตัวเลขเพื่อไปหน้ามอบวิชาหรือดูตารางของคนนั้น/กลุ่มนั้น

### หน้ากลุ่มเรียน

เรียงตามชั้นปี **ปวช.1 → ปวช.2 → ปวช.3 → ปวส.1 → ปวส.2** (มีหัวข้อแต่ละชั้น) แล้วตามแผนกวิชา แถวสลับสี
ทุกชั้นปีมีหัวข้อเสมอ (ชั้นที่ยังไม่มีกลุ่มก็แสดง) และมีปุ่ม **+ เพิ่มกลุ่ม ปวช.1** ฯลฯ ที่หัวข้อ — กดแล้วได้แถวใหม่ในชั้นนั้น ใส่ระดับชั้นให้แล้ว พิมพ์รหัส/ชื่อกลุ่มต่อได้เลย (ห้องย่อยพิมพ์ต่อท้ายในช่องระดับชั้น เช่น ปวช.1/2)
ชั้นปีดูจากช่องระดับชั้น → ชื่อกลุ่ม (เช่น "ส.2 …" = ปวส.2) → รหัสกลุ่ม · ช่องแผนกวิชาที่ยังว่างจะแสดงแผนกที่เดาไว้ (ตัวจาง มี "?") พิมพ์หรือเลือกเพื่อยืนยัน

### รายวิชาของแต่ละกลุ่ม (แผนการเรียนรายกลุ่ม)

หน้า **ข้อมูล → กลุ่มเรียน** → คอลัมน์ **วิชาที่เรียน** (กด "n วิชา →" หรือ "+ เพิ่มวิชา →")
- **เพิ่ม**: พิมพ์รหัสหรือชื่อวิชา ค้นจากคลังรายวิชาและรายวิชา 2/2568 แล้วกด "+ เพิ่ม" (วิชากิจกรรมลงพุธ 09:00 ล็อกให้เหมือนนำเข้าแผน)
- **เอาออก**: กด × — ถ้าเรียนรวมกับกลุ่มอื่น เอาออกเฉพาะกลุ่มนี้ · ถ้ามีครูหรือจัดตารางแล้ว ถามยืนยันก่อน
- **คัดลอกรายวิชาจากกลุ่มอื่น**: เช่น กลุ่มใหม่ของแผนกเดียวกัน เลือกกลุ่มต้นแบบแล้วกด "คัดลอก" (ไม่คัดลอกครู/ตาราง)
- วิชาที่เพิ่มไปรอที่ **มอบวิชาให้ครู → ยังไม่มีครู**

### ตรวจสอบข้อมูล (กลุ่มเรียนซ้ำ ฯลฯ)

**ตั้งค่า → ตรวจสอบข้อมูล** ตรวจให้ตลอดเวลา (สีแดง = ต้องแก้, สีส้ม = ควรตรวจ)
- **กลุ่มเรียนรหัสซ้ำ** หรือ **ชื่อซ้ำ** (เทียบโดยไม่สนช่องว่าง/จุด เช่น "ปวช.2 สารสนเทศ 67" กับ "ปวช.2สารสนเทศ67") → กด "เก็บอันนี้ รวมที่เหลือเข้ามา" ระบบย้ายรายวิชาและตารางมารวมให้
- **กลุ่มเรียนลงวิชาเดียวกันซ้ำ** (เช่น ครู 2 คนสอนวิชาเดียวกันให้กลุ่มเดียวกัน)
- **กลุ่มเรียนเรียนซ้อนเวลา** ทั้งตารางรายสัปดาห์และทั้งเทอม
- **ชั่วโมงเกินเวลาที่มี** (ชม./สัปดาห์ของกลุ่มมากกว่าช่องที่จัดได้)
- รายการที่ยังไม่เลือกกลุ่มเรียน, ชื่อครูซ้ำ, รหัสวิชาซ้ำ

ตอนวางรายชื่อกลุ่มเรียนจาก Excel ถ้าพบกลุ่มซ้ำจะแจ้งเตือนทันที และในตารางกลุ่มเรียนจะมีป้าย "ซ้ำ" ที่แถวนั้น

### เงื่อนไขการจัดตาราง

- **วันเรียน**: แต่ละวันเลือกได้ `เปิดสอน` / `ห้ามจัด` / `ไม่แสดง`
  - *ห้ามจัด* (เช่น วันศุกร์) ยังแสดงแถววันนั้นในใบตารางเป็นช่องว่าง แต่วางคาบไม่ได้
  - *ไม่แสดง* เอาแถววันนั้นออกจากใบตาราง
- **กิจกรรมประจำ** เช่น Home Room ทุกวันพุธ คาบ 1 (08:00–09:00): กดปุ่มเดียวสร้างให้ทุกกลุ่มเรียน และล็อกไว้
  - ผู้สอน = ครูที่ปรึกษาของกลุ่ม โดย **ครู 1 คนได้ 1 กลุ่มก่อน**
  - กลุ่มที่ไม่มีชื่อครูที่ปรึกษา / ชื่อไม่ตรงกับรายชื่อครู / ครูได้กลุ่มอื่นไปแล้ว จะ**เว้นว่าง**ไว้ เลือกครูเองได้ที่หน้ามอบวิชาให้ครู
  - กดอัปเดตซ้ำได้ ระบบจะไม่ทับครูที่เลือกไว้แล้ว
  - **แก้ Home Room จากหน้าจัดตาราง**: คลิกก้อน Home Room → แถบด้านบนเปลี่ยนครูที่ปรึกษาของกลุ่มนั้น และเปลี่ยนวัน/คาบเริ่ม/จำนวนคาบของทุกกลุ่มได้ทันที (ถ้าจะชนกับวิชาที่จัดไว้ ระบบถามก่อน) — PLC ทำแบบเดียวกันได้
  - **Home Room ตรงกับ "ครูที่ปรึกษา" ในข้อมูลกลุ่มเรียนเสมอ**: ใส่/แก้/วางชื่อครูที่ปรึกษาทีหลัง หรือเพิ่มกลุ่มใหม่ Home Room ปรับตามให้เอง — ยกเว้นครูที่เป็นที่ปรึกษากลุ่มอื่นอยู่แล้ว (Home Room เวลาเดียวกัน) จะเว้นว่างและบอกเหตุผลในตารางที่ปรึกษา; ถ้าเลือกครูที่มีกลุ่มแล้ว ระบบถามว่าจะย้ายมากลุ่มนี้ไหม
  - **เปลี่ยนครูที่ปรึกษาหลังล็อกแล้ว**: ตั้งค่า → เงื่อนไข → การ์ด Home Room → "เลือกครูที่ปรึกษาแต่ละกลุ่ม" (เลือกจากรายชื่อ) หรือพิมพ์ชื่อในคอลัมน์ "ครูที่ปรึกษา" หน้าข้อมูล → กลุ่มเรียน — ผู้สอน Home Room เปลี่ยนตาม วัน/คาบยังล็อกเดิม
- **PLC (ชุมชนการเรียนรู้ทางวิชาชีพ)** ทุกวันศุกร์ 17:00–19:00 (คาบ 9–10) 2 ชม.
  - ครูทุกคนมี PLC ยกเว้นที่เอาติ๊กออก (ตั้งค่า → เงื่อนไขการจัดตาราง → การ์ด PLC → เลือกครูที่เข้าร่วม)
  - ลงได้แม้วันศุกร์ห้ามจัด และในใบตารางสอนขึ้นแถว "PLC ชุมชนการเรียนรู้ทางวิชาชีพ (PLC)" ช. 2
  - เพิ่ม/ลบครูภายหลัง ระบบเพิ่ม/ลบ PLC ให้เอง
- **ช่วงเวลาห้ามจัด**: ใช้กับทุกคน เช่น ประชุมครูวันจันทร์คาบ 8–9

### นำเข้าแผนการเรียน (รายวิชาของกลุ่มเรียน)

หน้าแรก → **นำเข้าแผนการเรียน** วางข้อมูล `รหัสกลุ่ม | รหัสวิชา | ชื่อวิชา | ท | ป | น | ชื่อกลุ่มเรียน`
- สร้างรายวิชาและกลุ่มเรียนที่ยังไม่มี แล้ววาง "วิชา × กลุ่ม" ไว้ที่ช่อง **ยังไม่มีครู** ในหน้ามอบวิชาให้ครู
- วิชาเดียวกันของสายตรงและ ม.6 (รหัสกลุ่มต่างกันแค่หลักสุดท้าย) รวมเป็นรายการเดียว เรียนพร้อมกัน
- วิชากิจกรรมลงตารางวันพุธ 09:00–11:00 ให้อัตโนมัติ (ล็อก)
- **เรียนรวม**: กลุ่มที่รหัสต่างกันแค่หลักสุดท้าย (เช่น 693190501 สายตรง / 693190502 ม.6) วิชาเดียวกันเป็นรายการเดียว
- **วิชากิจกรรม** (ชื่อขึ้นต้นด้วย "กิจกรรม") ลงตารางล็อกไว้ให้ ค่าเริ่มต้น วันพุธ 09:00–11:00
- นำเข้าซ้ำได้ ไม่สร้างรายการซ้ำ
- ตัวอย่างข้อมูลจริง แผนกคอมพิวเตอร์ ภาคเรียนที่ 2/2569 (6 กลุ่มเรียน): [`data/แผนการเรียน-แผนกคอม-2-2569.tsv`](data/แผนการเรียน-แผนกคอม-2-2569.tsv)

### สัปดาห์ต่อภาคเรียน (ปวช. / ปวส.)

ชั่วโมงทั้งเทอม = ชม./สัปดาห์ × จำนวนสัปดาห์ของระดับ — ค่าเริ่มต้น **ปวช. 18 สัปดาห์, ปวส. 15 สัปดาห์** (เช่น ปวส. 4 × 15 = 60 ชม.) แก้ได้ที่ เงื่อนไข → สัปดาห์ต่อภาคเรียน
ระดับของกลุ่มดูจากช่องระดับชั้น ถ้าไม่มีใช้หลักที่ 3 ของรหัสกลุ่ม (2 = ปวช., 3 = ปวส.) · ตารางทั้งเทอมของ ปวส. จบที่สัปดาห์ที่ 15

### 2 โหมดตาราง

- **ตารางรายสัปดาห์**: เรียนวัน/เวลาเดิมทุกสัปดาห์ (ค่าเริ่มต้นของทุกวิชา)
- **ตารางทั้งเทอม**: สำหรับวิชาที่ต้องการวางเป็นรายวันจนครบชั่วโมงทั้งเทอม
  - ตั้งที่หน้ามอบวิชาให้ครู → คลิกชิปวิชา ช่อง "การจัด" → "ทั้งเทอม" และกำหนด "วันละ … ชม."
  - ชั่วโมงทั้งเทอม = ชม./สัปดาห์ × 18 สัปดาห์ เช่น 3 × 18 = 54 ชม. วันละ 4 ชม. = **13 วัน + 2 ชม.**
  - หน้าจัดตาราง → ตารางทั้งเทอม: แสดง **18 ตาราง (สัปดาห์ละ 1 ตาราง)** แบบเดียวกับตารางรายสัปดาห์ แถบเลขสัปดาห์ด้านบนกดเพื่อเลื่อนไปสัปดาห์นั้น
  - คลิกวิชาทางขวา แล้วคลิกคาบในตารางของสัปดาห์ที่ต้องการ (หรือลากวาง) ไปเรื่อย ๆ จนครบ หรือกด **เติม** ให้วางต่อเนื่องอัตโนมัติ
  - สีเทา = ตารางรายสัปดาห์ (มีทุกสัปดาห์) · สีตามวิชา = วิชาทั้งเทอม · ช่องเขียว = วางได้ · ช่องแดง = ชน
  - คลิกช่องที่วางแล้ว → คลิกช่องเขียวในสัปดาห์ไหนก็ได้ (หรือลาก) เพื่อย้าย และใช้เครื่องมือเหมือนรายสัปดาห์: **แบ่งเวลา (หัว+ท้าย), หัว +1/−1, ท้าย +1/−1, เอาออก** (เพิ่มได้ไม่เกินชั่วโมงทั้งเทอม)
  - แถบเครื่องมือและแถบเลขสัปดาห์ค้างอยู่ด้านบนเสมอ ใช้ได้ทันทีไม่ว่าจะเลื่อนไปสัปดาห์ไหน
  - พิมพ์ "ทั้งเทอม" ได้ตารางจริงของทุกสัปดาห์ หน้าละ 2 สัปดาห์
  - ตรวจชนกับตารางรายสัปดาห์และวิชาทั้งเทอมอื่นในสัปดาห์เดียวกัน

### ล้างตาราง

- ตารางรายสัปดาห์: ปุ่ม **ล้างตารางนี้** (ครู/กลุ่มที่เปิดอยู่ เอาเฉพาะคาบที่ไม่ล็อก)
- ตารางทั้งเทอม: ปุ่ม **ล้างตารางทั้งเทอมของครู/กลุ่มนี้** และ **ล้างตารางทั้งเทอมทั้งหมด** (ทุกครู ทุกกลุ่ม ตารางรายสัปดาห์ไม่เปลี่ยน) — ถามยืนยันก่อนทุกครั้ง

### เครื่องมือ (แถบเหนือตาราง)

เลือกคาบในตาราง (หรือการ์ดที่ยังไม่ได้จัด) แล้วใช้เครื่องมือบนแถบ:
- **แบ่งเวลา (หัว + ท้าย)**: หั่นก้อน เช่น 4 คาบ เป็น 1+3, 2+2, 3+1 แล้วลากส่วนท้ายไปวางที่อื่นได้
- **หัว / ท้าย +1 −1**: เพิ่ม/ลดคาบที่หัวหรือท้ายของก้อน ใช้เพิ่มเวลาให้ Block Course (ก้อนปกติคร่อมพักกลางวันไม่ได้)
- **รวมก้อนถัดไป**: รวมก้อนที่แบ่งไว้กลับเป็นก้อนเดียว
- **ล็อก / เอาออก**: ล็อกไม่ให้จัดอัตโนมัติย้าย หรือเอาคาบออกจากตาราง

แต่ละวิชามีสีประจำ (โทนอ่อน) และช่องตารางทุกช่องขนาดเท่ากัน ข้อความยาวจะตัดเป็น "…" (ชี้ค้างเพื่อดูเต็ม)

### หลักการสำคัญ

- **ภาระงาน 1 แถว** = ครู 1 คน + วิชา 1 วิชา + กลุ่มเรียน 1 กลุ่ม (หรือหลายกลุ่มที่**เรียนรวม**ในเวลาเดียวกัน ซึ่งชั่วโมงสอนของครูนับครั้งเดียว)
  ถ้าสอนวิชาเดียวกันให้หลายกลุ่มแต่แยกเวลากัน ให้เพิ่มเป็นคนละแถว (ปุ่ม ⧉ ช่วยทำสำเนา)
- **รูปแบบคาบ** เช่น `3` = เรียนติดกัน 3 คาบ, `2+2` = แบ่ง 2 ครั้ง ครั้งละ 2 คาบ ถ้าเว้นว่างไว้ ระบบคิดจาก ท.+ป. ของรายวิชาให้เอง
- **Block Course** = เรียนติดกันเป็นก้อนใหญ่ทุกสัปดาห์ ก้อนคาบข้ามพักกลางวันได้ เช่น `7` = คาบ 1–7
- **ตรวจชน**: ครูสอนซ้อน, กลุ่มเรียนเรียนซ้อน, คาบที่ตั้งไว้ว่าไม่ว่าง และช่วงเวลาห้ามจัด
  - ห้องเรียนชนกัน **ไม่ตรวจ** เป็นค่าเริ่มต้น เปิดได้ที่ เงื่อนไข → ห้องเรียน → "ตรวจห้องเรียนชนกัน"
- **เวลาไม่ว่าง**: ในหน้าจัดตาราง เลือกครูหรือกลุ่มเรียน → โหมด "เวลาไม่ว่าง" → คลิกช่องที่ไม่ว่าง
- **ล็อกคาบ**: คลิกคาบในตาราง → ล็อก คาบที่ล็อกไว้จะไม่ถูกย้ายหรือล้างเวลากดจัดอัตโนมัติ/ล้างตาราง

| ครู | ชื่อ-สกุล, วุฒิการศึกษา, แผนกวิชา, สาขาวิชา, หน้าที่พิเศษ |

### ชั่วโมงต่อสัปดาห์ของรายวิชา

หน้า **ข้อมูล → รายวิชา** ช่อง **ชม./สัปดาห์** แก้ได้: ตัวจางคือค่าเริ่มต้น (ท + ป) ถ้าสอนจริงไม่เท่านั้น (เช่น โครงงาน 0-12-4 สอนจริง 4 ชม.) พิมพ์ตัวเลขทับได้เลย · ลบตัวเลขออก = กลับไปใช้ ท + ป
รายการวิชา-ครูที่ไม่ได้ตั้งชั่วโมงเองจะเปลี่ยนตาม และคาบที่จัดไว้ที่ไม่ตรงแล้วจะกลับไปรอจัด

### คลังรายวิชา กับ รายวิชาของครู

หน้า **ข้อมูล → รายวิชา** เป็น*คลังรายวิชา* — เพิ่มวิชาที่นี่ (หรือกด "เพิ่มรายวิชา 2/2568") แล้ววิชายังไม่เป็นของครูคนไหน
ให้มอบให้ครูด้วยปุ่ม **มอบให้ครู →** ท้ายแถวในคลังรายวิชา หรือที่ **มอบวิชาให้ครู** → การ์ดครู → **+ เพิ่มวิชาให้ครูคนนี้** (เลือกวิชาแล้ว ชม./สัปดาห์ ใส่ให้ตาม ท+ป)

### รายวิชา 2/2568 (สำเร็จรูป)

รายวิชาที่เปิดสอนจริงภาคเรียนที่ 2/2568 ทุกแผนก 105 วิชา (รหัส ชื่อ ท-ป-น ถอดจากใบตารางสอน) อยู่ที่ `data/รายวิชา-2-2568.tsv`
- กดปุ่ม **เพิ่มรายวิชา 2/2568** ที่หน้าแรก หรือหน้าข้อมูล → รายวิชา — เพิ่มเฉพาะรหัสที่ยังไม่มี ไม่ทับของเดิม
- หรือพิมพ์รหัสในช่องวิชาตอน "+ เพิ่มวิชาให้ครูคนนี้" ระบบเพิ่มรายวิชานั้นให้เอง

ถ้ารหัสหรือชื่อซ้ำกับข้อมูลที่มีอยู่ ระบบจะปรับปรุงข้อมูลเดิมแทนการเพิ่มใหม่
